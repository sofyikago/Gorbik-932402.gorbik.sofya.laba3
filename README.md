# Лабораторная работа №3

Вёрстка макета страницы «О себе» с помощью Flexbox и CSS Grid. Вариант 1 — «Студент-разработчик»: витрина проектов и скриншоты.

## Реализовано
- Подключение стилей через внешний файл `style.css`, CSS-переменные в `:root` для цветов, шрифтов, отступов и теней
- **Flexbox:** горизонтальное адаптивное навигационное меню (`display: flex`, `flex-wrap: wrap`) и карточки раздела «Проекты» (3 шт.: название, стек технологий, кнопка «Подробнее»)
- Внутренняя компоновка карточки на `display: flex`: иконка слева, текст справа (на мобильном — столбиком)
- **Grid:** галерея «Скриншоты проектов» — 6 ячеек, каждая `<figure>` с `<img>` и `<figcaption>`; все строки одинаковой высоты (`grid-auto-rows: 1fr`)
- Адаптивность через медиа-запросы (mobile-first, брейкпоинты 600px и 992px):
  - карточки проектов: 1 колонка на мобильном, 2 на планшете, 3 на десктопе
  - галерея: 1 колонка на мобильном, 2 на планшете, 3 на десктопе
- Карточки проектов одинакового размера (`flex: 0 0 ...`), горизонтальной прокрутки нет
- Семантика: `<article>` для каждой карточки проекта, `<section>` для галереи, `<nav>` для меню, `<meta name="description">`
- Доступность: осмысленные `alt` у изображений, `aria-label` у кнопок «Подробнее», `:focus-visible`, учёт `prefers-reduced-motion`
- Контрастность текста не менее 4.5:1: в карточках проектов — тёмный полупрозрачный оверлей под белым текстом

## Структура
- `index.html` — разметка страницы
- `style.css` — стили и медиа-запросы
- `image/` — фото и скриншоты проектов
